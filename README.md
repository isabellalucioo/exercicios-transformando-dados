# Exercícios de Serialização/Desserialização em Java

Este repositório reúne exercícios desenvolvidos durante meus estudos de Java sobre Json e Gson
## 🛠 Tecnologias utilizadas

- Java
- IntelliJ IDEA

## 📚 Conceitos praticados

- Json
- Gson
- Serialização/Desserialização
- Classe Record e imuatibilidade
- 
## 📂 Exercícios

Os exercícios abordam diferentes desafios, como:

- O que são bibliotecas Java
- Instalar a biblioteca Gson no projeto, baixando e configurando o arquivo jar dela
- Utilizar a biblioteca Gson para converter um json em um objeto Java
- Criar um Record no Java, que é uma estrutura similar à uma classe, mas utilizado apenas para representar dados
- Flexibilizar a conversão de um json em um objeto Java, seguindo a documentação da biblioteca Gson.
